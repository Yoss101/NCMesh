Meshcore

Establish permanent, long-distance infrastructure to maintain constant connectivity across wide terrain. Engineered for dedicated backbone deployment, these high-elevation repeaters form a resilient network built to reliably route data over immense distances, keeping remote outposts and regional communities linked without commercial grid reliance.

How Meshcore Works

No Cell Service Needed

Meshcore radios communicate directly device-to-device using low-power radio waves. Stay connected during cell network outages, natural disasters, or while traveling through remote backcountry trails.

High-Hop Regional Backbones

The network protocol supports up to 64 hops. Messages travel smoothly through a dedicated chain of high-elevation infrastructure repeaters to bridge massive physical distances without causing local packet congestion.

Deterministic Routing Paths

Instead of constantly flooding the airwaves, Meshcore devices discovers and saves persistent routes. Once a path to a contact is known, traffic is routed cleanly through target repeaters to save critical bandwidth.

Persistent Room Servers

Dedicated infrastructure nodes act as BBS-style store-and-forward servers. They store message queues directly on the device, allowing offline or roaming users to retrieve missed chat logs later.

Meshcore Device Roles

Companion Node

User-facing node paired via Bluetooth or USB (Serial) to the MeshCore app. Handles direct messaging, node lists, and local settings management.

Repeater Node

Unattended relay node running specialized firmware. Extends signal range across the community by forwarding mesh packets without needing a phone connection.

Room Server Node

Dedicated fixed node hosting public or private group chat rooms. Stores messages for offline users to retrieve when back within radio range.

KISS TNC Node

Interfaces over USB (Serial) as a modem for external applications. Passes raw packet data directly to packet radio software and third-party radio clients.
